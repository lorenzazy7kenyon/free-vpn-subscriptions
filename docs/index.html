❓ Частые вопросы

Это правда бесплатно?

Да. Узлы публикуются волонтёрами в открытых источниках. Мы только собираем, проверяем и переупаковываем их.

Как часто обновляется?

Каждый час (GitHub Actions): загрузка источников → проверка TCP → GeoIP → публикация файлов. См. метку «обновлено» выше.

Почему узлы иногда не работают?

Бесплатные узлы живут минуты. В clash.yaml есть группа url-test — клиент сам выбирает самый быстрый рабочий узел и переключается при падении.

Безопасно ли это?

Узел видит весь ваш трафик. Никогда не используйте бесплатные узлы для банкинга и логинов — только для смены гео-локации на публичном контенте.
